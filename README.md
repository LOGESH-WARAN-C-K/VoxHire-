# 🎙️ VoxHire AI  
### Real-Time Interview Intelligence Platform  

🚀 AI-powered interview simulation with **voice, video, and behavioural intelligence**

---

## 🧠 Overview

VoxHire AI is a next-generation interview preparation platform designed to evaluate not just **what you say**, but **how you say it**.

It simulates real interviews using AI and provides **real-time feedback on confidence, communication, and behaviour**.

> 💡 Built for ET Gen AI Hackathon – Phase 2 Prototype Submission

---

## ❗ Problem Statement

Many candidates struggle in interviews despite having strong technical skills.

### Key Challenges:
- ❌ Lack of confidence  
- ❌ Poor communication clarity  
- ❌ Weak behavioural responses  
- ❌ Nervousness under pressure  

📌 Existing platforms focus only on Q&A — not behavioural intelligence.

---

## 💡 Solution

VoxHire AI acts as an **AI Interview Coach** that:

- 🎤 Conducts real-time interviews  
- 🧠 Generates adaptive questions  
- 📊 Analyzes speech & behaviour  
- 📹 Evaluates confidence via video  
- 📄 Generates structured feedback reports  

---

## 🎯 Target Users

- 🎓 Students preparing for placements  
- 💼 Early-career professionals  
- 🏫 Training institutes  
- 🧑‍💻 EdTech platforms  

---

## ✨ Key Features

### 🎤 AI Interview Simulation
- Real-time AI interviewer (Groq LLaMA 3)
- Adaptive follow-up questions

### 🧠 Behaviour Analysis Engine
- Filler word detection  
- Pause detection  
- Sentiment analysis  
- Confidence scoring  

### 📹 Video Intelligence
- Face detection (MediaPipe)  
- Engagement tracking  

### 📊 Real-Time Dashboard
- Confidence meter  
- Speech activity  
- Emotion indicator  

### 📄 Smart Feedback System
- Strengths & weaknesses  
- Improvement suggestions  
- Communication analysis  

### 🗂 Interview History
- Store sessions  
- View reports  
- Download PDFs  

---

## ⚙️ Tech Stack

### 🖥 Frontend
- React.js  
- Tailwind CSS  
- WebRTC  
- Web Speech API  

### ⚙️ Backend
- Node.js  
- Express.js  

### 🧠 AI Models
- Groq (LLaMA 3 / Mixtral)  
- Hugging Face Whisper (STT)  
- Edge TTS  
- BERT (Sentiment Analysis)  
- MediaPipe (Video Analysis)  

### 🔄 Orchestration
- Langflow (multi-agent system)  
- LangSmith (tracking & observability)  

### 🗄 Database
- MongoDB  

---

## 🧠 Multi-Agent Architecture

The system uses a **multi-agent AI pipeline**:
